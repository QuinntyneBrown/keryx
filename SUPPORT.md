# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/QuinntyneBrown/keryx/issues)
to track bugs and feature requests. Search existing issues before filing a new one to avoid
duplicates. For a new issue, file your bug or feature request as a new issue.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.

## Support policy

Support is provided by the maintainers on a best-effort basis through GitHub Issues.
