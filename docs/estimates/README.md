## Roadmap

1. admin-app: staff sign-in and the admin shell
2. sources: add a source, test its fetch, fetch respectfully and safely
3. collection and catalogue: the scheduled pipeline, idempotent ingestion, scoring, stored records
4. consumer-api: API keys, client authentication and the read endpoints
5. admin-app: articles, overview, run history, source health, settings, export
6. operations: alerts, audit, retention and the rest of telemetry
