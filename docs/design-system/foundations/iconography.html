Iconography

The Keryx mark and logo, and the thirty-three line icons of the admin with the one meaning each has.

Overview

One outline icon set (Lucide, ISC licence), inlined as SVG so it needs no font or sprite request and inherits the text colour. Icons support text; they rarely replace it.

  • 24-unit grid, fill: none, stroke: currentColor, stroke width 1.75, round caps and joins.
  • Three sizes: 14, 16 and 20 px.
  • The brand mark is not an icon: it has its own geometry and fixed colours.

The mark and logo

A cross whose right arm lifts into a K: the herald raising a call. The mark is a 40 × 40 viewBox with an ink tile (rx="10") and four volt strokes, 4.2 wide, square caps, mitre joins. The wordmark is lowercase “keryx” in Geist ExtraBold at 0.9 × the mark's size, tracked −0.045em, 10 px from the mark. Full rules and code are on the brand lockup page.

Mark sizes: 96, 64, 40, 32, 24, 16 px. Below 24 px use the mark without the wordmark.
  • Do not recolour the strokes.
  • Do not set volt on white.
  • Do not stretch, skew or rotate the lockup.

Usage

  • One meaning per icon. Arrow-right goes somewhere in the app; external-link opens a new tab; these two are not interchangeable.
  • Status has three shapes only: check-circle, alert-triangle, x-circle, plus info for neutral notes.
  • Source types have fixed icons: rss, globe, instagram, calendar, search.
  • A new icon comes from the same set at the same stroke; add it to this sheet with its meaning.

Accessibility

  • An icon beside text is decorative: aria-hidden="true".
  • An icon that is the only content of a control needs aria-label on the control; see icon button.
  • An icon that carries status is repeated in visually hidden text (“Failed: ”).
  • Status icons reach 3:1 against their surface in both themes.
