Foundation

Elevation

Four shadows used sparingly, a surface hierarchy that carries depth in the dark theme, and nine z-layers.

WCAG 2.2 AALight and darkSource: tokens/tokens.css

Overview

Keryx is flat. Cards, tables and lists sit on the page with a hairline edge and no shadow. Shadow is kept for the few things that float above the page: menus, toasts and dialogs. Depth is otherwise shown by surface colour.

  • --shadow-1: the switch thumb.
  • --shadow-2: reserved; nothing in the admin uses a raised card.
  • --shadow-3: menus, toasts, tooltips, the focused skip link.
  • --shadow-4: dialogs and sheets.
  • --shadow-focus: a focus ring drawn as a shadow, for elements where outline would be clipped.

Surface hierarchy

From lowest to highest: sunken, canvas, surface, raised. In the light theme canvas is grey and the two upper levels are white, separated by edges and shadow. In the dark theme each level is a lighter ink, because shadows are hard to see on dark: a dialog reads as raised by its colour.

Usage

  • If it does not float, it has no shadow.
  • One overlay at a time: a menu closes before a dialog opens; a dialog never opens a second dialog (confirmations replace, they do not stack).
  • Toasts sit above dialogs so a result is visible while a dialog is still open.
  • The backdrop is --color-bg-backdrop: 40 % ink in light, 65 % black in dark.
