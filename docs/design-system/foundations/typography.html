Typography

Geist and Geist Mono, a nine-step size scale, and eighteen role shorthands that components use instead of composing type themselves.

Overview

Two families, both bundled and self-hosted under the SIL Open Font License, never loaded from a CDN: Geist for everything and Geist Mono for ids, URLs, keys and code. Both are variable fonts (weights 100–900) in assets/fonts.

  • The admin's working size is 14 px, a deliberate departure from the 16 px body default: it is a dense tool used on laptops. Nothing is smaller than 12 px, and 16 px is used for section titles and lead text.
  • Sizes are in rem, so they follow the user's browser font size.
  • Numbers that are compared use tabular figures (.num).

  • Headings and stats use tight tracking (−0.02em); the wordmark alone uses −0.045em.

Usage

  • One h1 per page (--text-h1), then h2/h3 in order; use .text-h3 to style a heading independently of its level.
  • Prose is capped at --layout-measure (65ch); empty-state text at 44ch.
  • Mono is for things people copy or match exactly. It is not for emphasis.
  • Sentence case everywhere; see content.
  • Type does not scale with the viewport. The only responsive change is the status headline: 20 px, 24 px from 768 px.

Accessibility

  • Minimum text size is 12 px (captions, badges) and it always meets 4.5:1.
  • Text can be resized to 200 % without loss: all sizes are rem and containers wrap.
  • Nothing breaks with WCAG 1.4.12 text spacing (line height 1.5, letter spacing 0.12em, word spacing 0.16em, paragraph spacing 2×): no text sits in a fixed-height box.
  • Aggregated titles carry dir="auto" so right-to-left headlines read correctly.
