Overview

Keryx is ink and volt. Ink (#0E1116) is a cool near-black used for text, the sidebar and, in the light theme, primary actions. Volt (#C6F135) is the signal: the strokes of the mark, the current navigation item, progress, and in the dark theme the primary action. Everything else is a grey from the same ink ramp, plus four status colours.

  • Volt is only ever used on ink or as a fill. It is never text on a light surface: on white it is 1.3:1. Brand-toned text on light uses volt-800, a dark olive.
  • Components read semantic tokens (--color-*), never the palette. Themes override the semantic tier only.
  • The app background is paper grey (#F4F5F7); cards are white. In the dark theme surfaces get lighter as they rise.
  • Status is always colour plus an icon plus words.

Contrast

Every foreground and background pairing a component relies on is declared in tokens/contrast-pairs.json (96 pairs) and checked in both themes by check_contrast.py. The ratios below are computed live in your browser from the same tokens. Text needs 4.5:1; control edges, meaningful icons, chart marks and focus rings need 3:1. A pair listed at 1:1 is decorative and its note says what else carries the meaning.

  • Known limitation. Volt as a fill on a light surface (the progress bar, the running chart bar, the callout's edge) is about 1.3:1. Those marks are never the only signal: the same value is always in text beside them and in ARIA.
  • Metadata text is #656C79, not the design's #8A909B (3.2:1). Control edges are #808691: the mocks' #8A909B was 2.94:1 against the page background, where the Settings fields sit.

Usage

  • Pick the token by role, not by how it looks today: a hovered row is --color-bg-subtle even though it equals the canvas in light.
  • Never write a hex value, rgb(), white or black in a component or a template; the checker rejects them.
  • A new pairing goes into contrast-pairs.json before it ships.
  • To add a brand theme, add a [data-theme="name"] block that overrides semantic tokens only; see theming.
  • Charts: neutral marks are --color-border-inverse; status marks use the solid status colours; volt marks only the run in progress.

Tokens

All colour tokens are listed in the sections above, each with its live value in both themes: palette, surfaces, text, borders and focus, accent and brand, shell, status, on inverse.
