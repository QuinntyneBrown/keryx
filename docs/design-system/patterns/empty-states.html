Pattern

Empty and error states

What a screen shows when there is nothing to show: first run, no results, a failure, and the system pages for sign in, access denied and not found.

WCAG 2.2 AAComposes components

Overview

Every list in Keryx has four states besides its content: loading, empty, no results and error. They all use the empty state component, and each answers the same three questions: what is true, why, and what to do next. The same component, alone in a centred card, is the whole page when the person is signed out, not allowed, or lost.

  • An empty screen is never blank and never just “No data”.
  • Filters and navigation stay; only the content area is replaced.
  • Every server failure carries a reference id.

System pages: sign in, access denied, not found

A system page is one card: the lockup (as a non-link) or an icon, the page's h1, one or two sentences, optionally an alert explaining how the person got here, and one action. The card sits in .page-body--centered. Sign in and access denied use the bare app shell because there is nothing to navigate to; not found keeps the sidebar because the person is signed in.

Responsive behaviour

  • Centred at every width with 20 px side padding; text is capped at 44ch.
  • The system-page card is capped at 896 px and starts 48 px from the top.
  • Buttons wrap and stay centred.

Accessibility

  • The title is a heading at the correct level: h2 under a page header, the page's h1 on a system page.
  • An error that replaces content after an action moves focus to its heading and is announced with role="alert".
  • A no-results change is announced through the table's polite status (“0 articles match”).
  • Sign-in is delegated to the organisation's identity provider: no password field, no puzzle (WCAG 3.3.8).
  • After a session expires, sign-in returns to the screen the person was on, and saved work is said to be safe.
  • Access denied and not found do not reveal whether a hidden page exists.

Content

  • First run: “Nothing has been collected yet”, then how collection works, then the first step.
  • No results: repeat the query in quotes; offer to clear it.
  • Error: Keryx is the subject; say what still works; give the reference.
  • System pages: say who the admin is for and that Keryx never sees the password.
