Choice cards (radio group)

A radio group drawn as a row of small cards, each with an icon: the type of a source.

WCAG 2.2 AAStatus: stableNative <input type="radio">Block: .choice-card, .choice-grid

Overview

Use choice cards for one choice from two to four options that deserve an icon and decide what the rest of the form means. For more options use a select; for a setting on a page, a segmented control.

  • Exactly one card is selected; a default is always pre-selected.
  • The native radio is stretched invisibly over the card, so the browser provides the group's keyboard behaviour.

Anatomy

  1. Radio inputCovers the card with opacity: 0; it is what receives focus and the click.
  2. Icon and label14 px icon and the option name, centred.
  3. Card--control-height-md, hairline edge, --radius-md; the selected card takes an accent edge, a subtle fill and medium weight.

Sizes

One size: cards are <code>--control-height-md</code> tall and share the row equally.

States

Selection is the native :checked; the card reads it with :has().

Type
Type
  • Disabled: every card is disabled while the dialog is busy, and the selected one stays visibly selected.

Responsive behaviour

  • Two columns below 640 px, four columns from 640 px (.choice-grid).
  • Cards are 44 px tall on touch devices.
  • Labels are one word; a label that would wrap needs a select instead.

Theming

The selected edge is --color-accent (ink in light, volt in dark) on a --color-bg-subtle fill. Selection is shown by edge, fill and weight together, never by colour alone.

Accessibility

Role and pattern

Native radio inputs sharing a name, in a <fieldset> with a <legend>. See the WAI-ARIA radio group pattern.

Keyboard

KeyAction
TabMoves into the group, to the selected card, and out again.
ArrowRight / ArrowDownSelects the next card.
ArrowLeft / ArrowUpSelects the previous card.
SpaceSelects the focused card if none is selected.

Focus

The ring is drawn around the card when its hidden input has :focus-visible.

Labelling

Each card's text is its radio's label; the legend (“Type”) names the group. The icon is decorative.

Motion

Nothing animates.

Touch

36 px tall with a fine pointer and 44 px (--target-comfortable) on touch devices, because --control-height-md grows under (pointer: coarse). The whole card is the target.

Content

  • One word per card, the name people use for the thing: RSS, Website, Instagram, Eventbrite.
  • Order by how often each is used.
  • The legend is a noun: “Type”.
