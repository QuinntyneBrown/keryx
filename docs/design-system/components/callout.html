Callout

A volt-tinted panel for the one moment that must not be missed: a new API key that will never be shown again.

Overview

The callout is the loudest in-page message and is used once: at the top of the API screen right after a key is created. It carries the brand tint so it cannot be mistaken for a status alert.

  • A title sentence and a copy field.
  • It leaves when the person navigates away; the key is then gone for good.

Anatomy

  1. Container--color-brand-subtle with a volt hairline, --radius-lg, --space-4 padding (--space-5 from 768 px).
  2. Title--text-label in --color-fg-brand.
  3. ContentThe copy field.

Responsive behaviour

  • Fluid. The copy field's button wraps under the key on a phone.
  • Padding grows from 16 to 20 px at 768 px.

Theming

Pale volt with dark olive text and a volt edge in light; deep olive with pale volt text in dark. The edge is decorative: the tint and the text carry the message.

Accessibility

Role and pattern

role="status", so the sentence is announced when the page returns from the dialog. Focus moves to the Copy button.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter / SpaceOn Copy: copies the key.

Focus

After the New API key dialog closes, focus lands on Copy, not back on the header button.

Labelling

The title names the consumer the key is for.

Contrast

Title

Motion

Nothing animates.

Touch

The Copy button is 36 px, 44 px on touch.

Content

  • Say what was created, for whom, and that this is the only chance: “Copy it now — it won’t be shown again.”
  • Do not put anything else in a callout; its force comes from being rare.
