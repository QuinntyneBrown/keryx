Progress bar

A thin volt bar that fills as the collector works through its sources.

WCAG 2.2 AAStatus: stablerole="progressbar"Block: .progress

Overview

Use a progress bar when the amount of work is known and takes more than a few seconds: a run checking 64 sources. For a wait of unknown length use a spinner; for content that is loading, a skeleton.

  • Determinate: width from --value.
  • Indeterminate: a 40 % bar sweeping across.
  • It always sits next to text that states the same progress in numbers.

Anatomy

  1. Track--space-1 (4 px) tall, --color-border-default, square ends so it can run edge to edge in a card.
  2. Bar--color-brand.

Variants

Started 9:46 AM · 38 of 64 sources checked

Determinate with its sentence; indeterminate

Sizes

One size: 4 px tall, full width.

States

StartPart wayCompleteIndeterminate
Progress

Both themes

  • On completion the bar is removed and the status card changes state; it does not linger at 100 %.

Responsive behaviour

  • Full width of its container at every size; in the status card it runs edge to edge between the summary and the history strip.

Theming

Volt on the divider-coloured track. In the dark theme that is a bright, high-contrast bar. In the light theme volt on a pale track is about 1.3:1, so the bar is treated as decorative: the sentence beside it and aria-valuenow carry the value.

Accessibility

Role and pattern

role="progressbar" with aria-label, aria-valuemin, aria-valuemax and aria-valuenow in real units (sources, not percent). The indeterminate form omits the value attributes.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable.

Labelling

Named for what is counted: “Sources checked”. The adjacent sentence is a polite live region updated every few seconds, not on every source.

Contrast

Bar on track (decorative in light)
Progress sentence

Motion

The indeterminate bar sweeps once every --duration-deliberate; under reduced motion it stops and the sentence alone reports progress. The determinate bar's width changes without a transition.

Touch

Not interactive, so no target size applies.

Content

  • Always pair it with numbers: “38 of 64 sources checked”.
  • Say how long it usually takes when it starts: “This usually takes about 4 minutes.”
