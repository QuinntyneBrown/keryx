Checkbox

Zero or more choices from a short list, each with room for a line of explanation.

WCAG 2.2 AAStatus: stableNative <input type="checkbox">Block: .check, .check-list

Overview

Use checkboxes when several options can be on at once and the choice is applied on submit: the scopes of an API key. A setting that takes effect on Save and reads as on/off is a switch. With type="radio" the same block is a plain radio list; the mocks use choice cards for that instead.

  • The group is a <fieldset> with a <legend>.
  • Each option can carry a description in <small> under its label.

Anatomy

  1. BoxThe native control at 16 px, tinted with accent-color: var(--color-accent).
  2. Label and descriptionLabel in body text (mono for a scope name); description in --text-caption, muted.
  3. RowThe whole <label> is the target; --space-2-5 between box and text.

Sizes

One size: a 16 px box with a label row at least 24 px tall.

States

Native states, drawn by the browser in the accent colour.

Scopes
Scopes
  • Indeterminate is set from script (input.indeterminate = true) for a “select all” box; no mock has one.
  • Invalid: when at least one scope is required, the error goes under the list and the fieldset gets aria-describedby.

Responsive behaviour

  • Options stack in one column at every width.
  • Labels and descriptions wrap beside the box, never under it.
  • The label row is the target, so it comfortably exceeds 24 px; rows are 8 px apart.

Theming

accent-color follows --color-accent: an ink box with a light tick in the light theme, a volt box with an ink tick in the dark theme. The browser picks the tick colour for contrast.

Accessibility

Role and pattern

Native checkboxes in a <fieldset> with a <legend>. See the WAI-ARIA checkbox pattern.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
SpaceToggles the focused box.

Focus

The browser draws the shared ring around the box.

Labelling

The <label> wraps the input, so the label and its description are both read. The legend names the group.

Motion

Touch

The whole label row toggles the box. Rows are at least 24 px tall and 8 px apart.

Content

  • Label what is granted, not the action of ticking: “articles:read”, not “Enable articles”.
  • The description says what the option gives in plain words.
  • Pre-tick the option nearly everyone needs (articles:read).

Code

BEM block: .check, .check-list. The Angular component lives in frontend/projects/components/src/check/ and keeps these class names; the e2e page objects locate by them.

<label class="check">

<span class="check__text">

<small>Published articles and their summaries</small></span></label></div></fieldset>
