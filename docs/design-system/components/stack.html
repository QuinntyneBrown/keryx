Stack, cluster, rail and split

The layout primitives that put space between components, so no component carries an outer margin.

Overview

Components have no margin of their own. Vertical rhythm comes from .stack, inline groups from .cluster, and the two page grids from .layout-rail and .split. In Angular these are global utility classes, not components.

  • Stack: a column with one gap (8, 16, 24 or 32 px).
  • Cluster: a wrapping row with an 8 px gap, aligned to the centre.
  • Rail: content plus a 340 px rail from 1024 px (Overview), or rail first (Runs).
  • Split: two near-equal columns from 1280 px (API endpoints and the code panel).

Anatomy

  1. Stackdisplay: flex; flex-direction: column; gap: var(--space-4).
  2. Clusterdisplay: flex; flex-wrap: wrap; gap: var(--space-2); align-items: center.

Responsive behaviour

  • .layout-rail is one column below 1024 px and 1fr 340px from there; --start puts the rail first.
  • .split is one column below 1280 px.
  • .stats is three columns; .stats--4 is two columns below 640 px and four above.
  • .field-grid is one column below 640 px and two above.
  • .from-lg and .until-lg show an element only from, or only below, 1024 px.

Theming

No colour. Gaps are spacing tokens, so they are the same in every theme.

Accessibility

Role and pattern

Purely visual. They must not change the reading order: DOM order is visual order at every width, including when a rail moves below its content.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Nothing to focus. Children keep their DOM order for Tab.

Labelling

No labels. Do not put role on a layout wrapper.

Contrast

Text on page

Motion

Nothing animates.

Touch

Not interactive, so no target size applies.

Content

  • Sections of a page are 24 px apart (.stack--lg); the API page uses 32 px between its three larger blocks.
  • Inline groups of buttons or badges are 8 px apart.
  • If two things need a different gap from the scale, they are probably different groups.
