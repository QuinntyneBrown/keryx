Sidebar and top bar

The ink frame of the admin: the lockup, the six destinations, and the next collection. Below 1024 px the same block is the top bar.

Overview

There is one navigation component. From 1024 px it is a sticky left sidebar; below that it lies across the top with the links in a horizontally scrolling row. It is not a drawer and has no menu button: six short links fit.

  • Head: the lockup and an “Admin” tag.
  • Nav: six navigation links.
  • Foot (sidebar only): when the collector runs next and who is signed in.

Anatomy

  1. HeadLockup and tag; --space-5 inline padding.
  2. NavigationA column of links with --space-1 between (a scrolling row below 1024 px).
  3. FootA hairline, the next collection, then avatar, name and role.

The two forms are one block at two widths. Narrow this window below 1024 px to see the top bar; the specimen follows the viewport.

Sizes

240 px wide (<code>--layout-sidebar-width</code>) and the full height of the viewport from 1024 px; full width and as tall as its two rows below.

States

The sidebar's own states are the page it marks and what its footer reports.

StateWhat changes
Current pageOne link has aria-current="page".
ProblemsThe Runs link carries a count of failing sources.
CollectingThe footer says “Collecting now…” in place of the next time.
Top barFooter hidden; links scroll sideways.

  • The sidebar is ink in both themes: --color-shell-bg is ink-950 in light and one step darker than the canvas in dark.

Responsive behaviour

  • Below 1024 px: static at the top of the page, links in one row with overflow-x: auto, footer hidden. It scrolls away with the page; it is not sticky, so it never covers focused content.
  • From 1024 px: sticky, 100dvh tall, links stacked, footer pinned to the bottom, scrolls on its own if the window is short.
  • The next-collection time, hidden with the footer on small screens, is repeated in the Runs page description.

Theming

It reads the six --color-shell-* tokens and sets --color-focus-ring to --color-brand for everything inside it, because an ink ring would vanish on ink.

.sidebar { --color-focus-ring: var(--color-brand); }

Accessibility

Role and pattern

An <aside> containing <nav aria-label="Primary">. Links are plain <a> elements; the current one has aria-current="page".

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows the focused link.

Focus

A volt ring, 3:1 or better against the ink. In the scrolling top bar the browser scrolls a focused link into view.

Labelling

The nav is labelled “Primary”. The lockup link is labelled “Keryx, go to overview”. The avatar is decorative because the name is beside it.

Contrast

Link
Current link
Caption
Focus ring

Motion

Only the links' hover fill animates.

Touch

Links are 36 px tall, 44 px on touch devices; in the top bar they are 4 px apart.

Content

  • Six one-word destinations, in the order of the pipeline's story: Overview, Articles, Runs, Sources, API, Settings.
  • The footer states a fact, not a label: “12:00 PM · in 2h 14m”, “Every 6 hours, Toronto time”.
  • The tag says which Keryx surface this is: “Admin”.
