Page header

The top of every screen: its name, one sentence of live context, and the screen's main action.

Overview

Each of the six screens starts with a page header. The description is not a slogan: it carries the facts that frame the screen (“64 sources across the GTA · 2 failing · 1 needs a look”).

  • At most one primary action, at the right.
  • Screens with nothing to do (Settings) have no actions.

Anatomy

  1. TitleThe page's only h1, --text-h1 with tight tracking.
  2. DescriptionOne muted line of current facts, --space-1 below.
  3. ActionsButtons, right-aligned from 640 px; the primary one last.

Sizes

One size. Top padding grows from <code>--space-6</code> to <code>--space-8</code> at 768 px.

States

The header stays put through every state of its screen; only its description and action change.

Screen stateDescriptionAction
DefaultLive facts.Enabled.
LoadingThe static sentence; no counts yet.Disabled.
ErrorThe static sentence.Disabled; Try again is in the error state below.
Running“Collecting now…”Run now disabled.

Responsive behaviour

  • Below 640 px the actions sit under the text, left-aligned, at their natural width.
  • From 640 px: one row, text left, actions right, aligned to the text's baseline.
  • The title wraps and balances (text-wrap: balance); it is never truncated.
  • Side padding is the page margin, so the header lines up with the body.

Theming

It reads semantic tokens only, so both themes and prefers-contrast: more restyle it with no rule of its own.

Accessibility

Role and pattern

A <header> inside <main> containing the page's single <h1>. (The specimens on this page use an h2 styled as the title, because this documentation page has its own h1.)

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter / SpaceActivates the focused action.

Focus

After navigation, focus is placed on the h1 (with tabindex="-1") so the new page is announced.

Labelling

The h1 matches the navigation link and the first part of the <title>.

Motion

Nothing animates.

Touch

Its buttons are 36 px tall, 44 px on touch.

Content

  • The title is the navigation label, unchanged.
  • The description is one sentence or a row of facts separated by “ · ”; numbers are real and current.
  • Counts use thousands separators: “18,432”.
