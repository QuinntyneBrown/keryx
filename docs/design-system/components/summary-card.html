Summary card

One identifying value and three numbers about it: the API's base URL with its requests, latency and error rate.

WCAG 2.2 AAStatus: stable<section>Block: .summary-card

Overview

A simpler sibling of the status card, used at the top of the API screen. The lead is a value people copy; the stats say how it is doing.

  • Lead on the left, stats on the right from 768 px.
  • The lead value is mono, medium weight, and truncates.

Anatomy

  1. LeadA caption and a mono value (--text-code-lg).
  2. StatsThree stats; under the lead with a rule above, beside it with a rule at the left from 768 px.

Responsive behaviour

  • Column below 768 px, row from 768 px.
  • The base URL truncates rather than wrapping; it stays selectable in full.

Theming

It reads semantic tokens only, so both themes and prefers-contrast: more restyle it with no rule of its own.

Accessibility

Role and pattern

A <section aria-label>; the value is in a <code> element.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable.

Labelling

The caption (“Base URL”) labels the value by proximity; the stats are a <dl>.
