Spinner

A small turning ring for a wait of unknown length: a button that is submitting, a run that is collecting.

WCAG 2.2 AAStatus: stable<span>Block: .spinner

Overview

Use a spinner inside the thing that is busy, never over the whole page. First loads use skeletons; measurable work uses progress.

  • In the status disc while a run is collecting (20 px).
  • In a busy button, where it is drawn by aria-busy and needs no element (14 px).

Anatomy

  1. RingA 2 px border in currentColor with one transparent quarter, turning once every --duration-spin.

Responsive behaviour

Theming

currentColor: it takes the colour of the text or disc it sits in.

Accessibility

Role and pattern

The ring is aria-hidden. The wait is announced by text in a role="status" region: “Collecting news now…”, “Saving your changes…”.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable.

Labelling

Always paired with a sentence that says what is happening; a spinner alone is silent.

Contrast

Ring in the info disc
Ring on the primary button

Motion

Under reduced motion the ring stops turning and shows as a static three-quarter ring; the status sentence still says what is happening.

Touch

Not interactive, so no target size applies.

Content

  • The sentence names the activity with an ellipsis: “Adding…”, “Collecting news now…”.
  • If a wait passes ten seconds, say why or offer a way out.
