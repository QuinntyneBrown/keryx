Divider

A hairline that separates two groups when space alone does not.

Overview

Most separation in Keryx is built into components: list rows, table rows, settings sections, dialog and panel footers and the menu divider all draw their own hairline. Use .divider only between blocks that have no such edge. Prefer space first.

  • Horizontal: an <hr>.
  • Vertical: between inline groups in a toolbar.
  • Labelled: a caption centred on the line (“or”).

Anatomy

  1. Line--border-width-hairline of --color-border-default with --space-4 above and below.

Responsive behaviour

  • Horizontal dividers span their container.
  • A vertical divider is dropped when its row wraps, because it would end a line.

Theming

--color-border-default: ink-100 in light, ink-800 in dark. Under prefers-contrast: more it takes the strong border colour.

Accessibility

Role and pattern

An <hr> (which is a separator), or role="separator" on another element. A purely visual line inside a component is CSS and has no role.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable.

Labelling

A labelled divider's text is read as the separator's name.

Contrast

Line (decorative)
Label

Motion

Nothing animates.

Touch

Not interactive, so no target size applies.

Content

  • A label is one short word: “or”.
  • If a divider needs a heading, it is a new section: use a section head.
