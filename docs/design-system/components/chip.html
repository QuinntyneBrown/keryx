Chip

A removable value in a list the person curates: the topics Keryx looks for, the terms it excludes, the areas it focuses on.

WCAG 2.2 AAStatus: stableList of removable itemsBlock: .chip, .chips

Overview

Chips show a set of short text values that can be removed one by one and added to. Adding opens the Add a topic dialog; the repository forbids inline forms. To filter a table by one of several categories use filter chips; to show a status use a badge.

  • The chip itself is not a control. Its remove button is.
  • The dashed Add chip ends the list.
  • A chip just added is tinted with the brand colour until the form is saved.

Anatomy

  1. ChipA pill --control-height-sm tall with a hairline edge.
  2. ValueBody text, exactly as entered.
  3. Remove buttonA --target-min (24 px) round button with a 14 px ×.
  4. Add chipDashed edge, plus icon, opens the dialog.

Sizes

One size: 32 px tall (44 px on touch) with a 24 px remove button.

States

The remove button and the Add chip have hover and focus; the chip body does not react.

  • New (.chip--new): brand-tinted until the form is saved, so the person can see what Save changes will add.
  • Removing a chip moves focus to the next chip's remove button, or to Add when it was the last.

Responsive behaviour

  • Chips wrap onto as many rows as needed with --space-1-5 between them.
  • A chip never truncates its value; a value longer than the row wraps the chip onto its own line.
  • On touch devices the chip is 44 px tall, which gives the 24 px remove button the spacing WCAG 2.5.8 asks for.

Theming

Chips are surface-coloured with a decorative edge. The new chip uses --color-brand-subtle with --color-fg-brand text: pale volt with dark olive text in light, deep olive with pale volt text in dark.

Accessibility

Role and pattern

A <ul> with an aria-label matching the field label; each chip is an <li> containing its text and a real <button>.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter / SpaceOn a remove button: removes the chip. On Add: opens the Add a topic dialog.
Backspace / DeleteOn a remove button: also removes the chip.

Focus

Each remove button and the Add chip are tab stops. After a removal focus moves to the next remove button so it is never lost.

Labelling

Each remove button names its chip: “Remove fitness”. Add names its list: “Add to Topics”. A polite status announces “fitness removed”.

Contrast

Value
Remove glyph

Add label

Motion

Nothing animates. Chips appear and disappear without animation.

Touch

The remove button is 24 × 24 px, the WCAG 2.2 minimum, with the chip's 4 px padding and 6 px gaps around it; the chip is 44 px tall on touch.

Content

  • Lower case for topics and terms as they will be matched (“sports ministry”); proper case for places (“Richmond Hill”).
  • One to three words. A chip is a term, not a sentence.
  • Values come from staff, but treat them as untrusted when rendering: text only.
