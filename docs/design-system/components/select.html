Select

One choice from a list that is too long to show at once: a region, a category.

WCAG 2.2 AAStatus: stableNative <select>Block: .select

Overview

Keryx uses the native select everywhere: it is keyboard-complete, opens the platform picker on phones and needs no script. Up to five options that fit on a line are a segmented control or choice cards instead.

  • In a field, full width, with a label above (Region in the source dialogs).
  • In a toolbar, auto width (.select--auto), where the first option names the filter (“All regions”) and the label is visually hidden.

Anatomy

  1. ControlSame height, edge, radius and padding as a text field.
  2. CaretTwo CSS gradients forming a 5 px chevron in currentColor, --space-4 from the right edge; no image.

Sizes

One height (<code>--control-height-md</code>); full width, or the width of its longest option with <code>.select--auto</code>.

States

The same states as a text field.

DefaultHoverFocusInvalidDisabled
Select

Both themes

  • Open is drawn by the browser and the operating system; it is not styled.

Responsive behaviour

  • In the Articles toolbar the two selects wrap under the search field when the row is narrower than their combined width.
  • On phones the native picker opens as a sheet or wheel, which is why the control is not replaced by a custom listbox.
  • 44 px tall on touch devices.

Theming

The caret is drawn in currentColor, so it follows the text colour in both themes. color-scheme in the tokens makes the browser's option list dark in the dark theme.

Accessibility

Role and pattern

A native <select>. Changing it filters the table at once but never navigates away or submits a form (WCAG 3.2.2).

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
ArrowUp / ArrowDownChanges the selection.
Space / Alt+ArrowDownOpens the list.
Any letterJumps to the next option starting with it.
EscCloses the list, keeping the previous value.

Focus

As for the text field: the ring replaces the edge with no offset.

Labelling

A <label for>; visually hidden in a toolbar, where the first option (“All regions”) shows what the filter is.

Motion

The edge colour changes over --duration-fast.

Touch

36 px tall with a fine pointer and 44 px (--target-comfortable) on touch devices, because --control-height-md grows under (pointer: coarse).

Content

  • The reset option of a filter names the whole set: “All regions”, “All categories”.
  • Order options as people look for them: Toronto first, then the GTA cities, then Ontario and Global.
  • Option text is a noun, sentence case, no punctuation.
