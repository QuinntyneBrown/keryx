Copy field

A value shown once in full with a button that copies it: a new API key.

WCAG 2.2 AAStatus: stable<code> + buttonBlock: .copy-field

Overview

Used inside the callout that appears after a key is created. Keryx stores only the first characters of a key, so this is the single moment it can be copied.

  • The value is mono, on a surface chip, truncated if it cannot fit.
  • Copy confirms with a toast.

Anatomy

  1. Value--text-code-md on --color-bg-surface, --radius-md; grows to fill the row.
  2. Copy buttonA default button with the copy icon.

  • Copied: the button reads “Copied” for two seconds and a toast says the key is on the clipboard. If the clipboard is blocked, a danger toast says to select the key and copy it by hand.

Responsive behaviour

  • Value and button share a row; the button wraps under the value when the row is too narrow.
  • The value truncates visually but is selectable in full.

Theming

The value chip is the surface colour so it stands out on the callout's volt tint in both themes.

Accessibility

Role and pattern

A <code> element and a <button>.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter / SpaceCopies the value.

Focus

The shared ring (--focus-ring-width of --color-focus-ring, offset by --focus-ring-offset) appears on :focus-visible only, so a pointer click does not show it. It is ink in the light theme and volt in the dark theme, on the sidebar and on toasts.

Labelling

The button is “Copy”; in a list of several it names its value (“Copy key for Covenant Cycling site”). The confirmation is announced by the toast's live region.

Motion

Nothing animates.

Touch

36 px tall with a fine pointer and 44 px (--target-comfortable) on touch devices, because --control-height-md grows under (pointer: coarse).

Content

  • Never log, echo or re-display the full value after this screen.
  • Say it is the only chance: “Copy it now — it won’t be shown again.”
