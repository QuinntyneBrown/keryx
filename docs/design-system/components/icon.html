Icon

A 24-unit line glyph drawn in the text colour, at 14, 16 or 20 px.

WCAG 2.2 AAStatus: stableInline SVGBlock: .icon

Overview

Icons are inline SVGs from one outline set (Lucide), stroked at 1.75 units with round caps and joins. They inherit currentColor, so they take the colour of the text beside them. The full sheet is on the iconography page.

  • An icon next to text is decorative: aria-hidden="true".
  • An icon alone is a control and needs a name; see icon button.
  • Tone modifiers colour status icons.

Anatomy

  1. GlyphviewBox="0 0 24 24", fill: none, stroke: currentColor, stroke-width: var(--icon-stroke).

Variants

Success, warning, danger, info, muted, inherited

Sizes

Three sizes.

.icon--sm 14 px (in buttons, links) · default 16 px (navigation, rows) · .icon--lg 20 px (status discs, timeline)

States

Icons have no states; they follow their parent's colour.

Responsive behaviour

  • Sizes are fixed in rem, so icons scale with the user's font size.
  • flex: none keeps an icon from shrinking next to long text.

Theming

currentColor everywhere; the tone modifiers use the status icon tokens, which are 3:1 or better on surface in both themes.

Accessibility

Role and pattern

aria-hidden="true" and no <title>. Meaning is given by adjacent or visually hidden text.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable (focusable is not needed on modern engines).

Labelling

Never rely on the icon's shape for status: “Failed: ”, “Warning: ” in hidden text.

Motion

Nothing animates.

Touch

Not interactive, so no target size applies.

Content

  • One meaning per icon across the product.
  • Arrow: goes somewhere in the app. External-link: opens a new tab.
  • Check-circle, alert-triangle and x-circle are the only status shapes.
