Link

Links go somewhere: to another screen, to the run behind an issue, or out to the source that published an article.

Overview

Use a link when activating it navigates. If it changes data or opens a dialog it is a button. Keryx stores a link to every source, so external links are common and follow one rule: they open in a new tab, say so, and only ever open http(s) addresses.

  • Inline: ink text with an underline in the edge colour that darkens on hover.
  • Standalone: a label with a trailing arrow, used in section heads (“View all 18,432”, “All runs”).
  • External: a trailing external-link icon and hidden text “(opens in a new tab)”.
  • Row title: the article title in a table is the row's one link; its hit area covers the row.

Anatomy

  1. TextSays where it goes. Underlined, so colour is not the only cue.
  2. Direction icon (optional)Arrow for a place inside the app, external-link for a new tab. 14 px, decorative.
  3. Hidden suffix (external)“(opens in a new tab)” in .visually-hidden.

Sizes

Links take the size of the text they sit in. Standalone links are 14 px medium, or 12 px with <code>.section-head__link--sm</code>.

States

Hover strengthens the underline; standalone links, which have no underline, darken instead. Visited links are not restyled: an admin revisits the same screens all day.

  • There is no disabled link. If the destination is unavailable, remove the link and say why.

Responsive behaviour

  • Links wrap with their text. A long URL shown as a link uses .truncate inside a min-width: 0 parent and keeps the full address in the accessible name.
  • Section-head links stay on the heading's row and never wrap under it; the heading truncates first.
  • On touch, a standalone link's line box is at least 24 px tall; inline links in running text are exempt from target size.

Theming

Link text is --color-fg-link, the same ink as body text, so the underline carries the affordance. Volt is never used for a link on a light surface; in the documentation the hover colour is --color-fg-link-hover, the dark olive volt-800.

Accessibility

Role and pattern

A native <a href>. External links add target="_blank" rel="noopener noreferrer". A source URL from aggregated content is rendered only when its scheme is http or https.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows the link. Space does not: that is how a link differs from a button.

Focus

The shared ring (--focus-ring-width of --color-focus-ring, offset by --focus-ring-offset) appears on :focus-visible only, so a pointer click does not show it. It is ink in the light theme and volt in the dark theme, on the sidebar and on toasts. The row-title link draws its ring around the title text, not the whole row.

Labelling

The link text makes sense alone: “Open original”, “View all 18,432”, the article title. Never “click here”. External links add the hidden suffix so the new tab is not a surprise.

Motion

The underline colour changes with no transition. Nothing animates.

Touch

Standalone links have a 24 px minimum line box. The row-title link's hit area is the whole row (::after with inset: 0), far above 44 px.

Content

  • Say where the link goes, with the number when there is one: “View all 18,432”.
  • For a source, show the host and path people recognise (“redeemedrun.ca/feed”), not the full URL with its scheme.
  • Titles and names that came from a source are untrusted: render them as text, never as HTML.
