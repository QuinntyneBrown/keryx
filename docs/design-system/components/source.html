Source cell

How a source is identified in a row: a type icon in a tile, the organisation's name, and the address Keryx fetches.

Overview

The source cell is the primary cell of the Sources table. It carries the provenance of everything that source produced: who publishes it and where exactly Keryx reads it.

  • The tile's icon is the source type: RSS, website, Instagram, Eventbrite, news query.
  • Name on the first line, address in mono on the second; both truncate.

Anatomy

  1. Type tile--size-tile (32 px), --color-bg-subtle, --radius-md, 16 px icon.
  2. Name--text-label, truncated.
  3. AddressMono caption, subtle, truncated; a hidden prefix says the type.

Responsive behaviour

  • Name and address truncate with an ellipsis inside the cell (min-width: 0).
  • Below 1024 px the source's health is added as a third line.

Theming

It reads semantic tokens only, so both themes and prefers-contrast: more restyle it with no rule of its own.

Accessibility

Role and pattern

An icon tile and two lines of text. The icon is decorative; the type is given as hidden text before the address (“RSS: redeemedrun.ca/feed”).

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable in the Sources table; the row's action button is.

Labelling

A truncated name keeps its full text in the DOM, so it is read in full.

Contrast

Icon on tile

Motion

Nothing animates.

Touch

Not interactive, so no target size applies.

Content

  • The name is the organisation as it publishes itself.
  • The address drops the scheme and “www.”: “redeemedrun.ca/feed”.
  • Never show a person's private account; sources are organisations.
