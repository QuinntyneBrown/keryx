List

A bordered stack of rows for things that are read top to bottom: the latest articles, the run history, the issues in a run.

Overview

Use a list for a short series of items with a title and a line of detail. If people compare fields across rows, use a table.

  • Static rows: title, meta, and an aside (a time, a badge).
  • Interactive rows (.list__item--interactive): the whole row is a link; the current one is filled. The run history uses this with a status icon (.run-item).
  • Wrapping rows (.list__item--wrap): content and actions that stack below 640 px, as in a run's issues.

Anatomy

  1. Row--space-3 by --space-4 padding (--space-5 inline from 768 px), a hairline above every row but the first.
  2. BodyTitle in --text-label; meta in caption, muted, truncated to one line.
  3. AsideRight-aligned caption-size extras, stacked.

Responsive behaviour

  • Rows are fluid. Meta lines truncate with an ellipsis; titles wrap.
  • Inline padding grows from 16 px to 20 px at 768 px.
  • Wrapping rows put their actions under the text below 640 px and beside it above.

Theming

Same surfaces as the table: hover is subtle, current is accent-subtle.

Accessibility

Role and pattern

A <ul> (or <ol> when order matters). An interactive row is one <a> filling the <li>; the open one has aria-current="true".

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterOpens the focused row.

Focus

The shared ring (--focus-ring-width of --color-focus-ring, offset by --focus-ring-offset) appears on :focus-visible only, so a pointer click does not show it. It is ink in the light theme and volt in the dark theme, on the sidebar and on toasts. It is drawn inside the list's clipped corners.

Labelling

A status icon is decorative; the status is repeated as hidden text at the start of the row (“Completed with issues: Today, 6:00 AM”).

Motion

Touch

Interactive rows are about 56 px tall and full width.

Content

  • Title: the thing itself. Meta: facts joined by “ · ”.
  • The aside holds at most a time and one badge.
  • Issue rows give the technical detail in mono and the pattern in plain words (“Failing 4 runs in a row”).
