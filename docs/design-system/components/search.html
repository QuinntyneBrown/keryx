Search field and toolbar

A text field with a magnifier that filters the table under it, and the toolbar row it shares with the other filters.

WCAG 2.2 AAStatus: stable<input type="search">Block: .search, .toolbar

Overview

Search narrows the list on the same screen; it does not navigate. It sits first in a .toolbar, grows to fill the row, and the selects beside it keep their natural width.

  • Results update as the person types, after a short pause; there is no search button.
  • When nothing matches, the table is replaced by a compact empty state that repeats the query and offers Clear search.

Anatomy

  1. Magnifier16 px, --color-fg-subtle, inside the field at --space-3 from the left; decorative.
  2. FieldA text field with --space-8 left padding; grows from a --layout-search-basis basis.
  3. ToolbarA wrapping flex row with --space-2 gaps.

Sizes

One size, the height of a text field.

States

It has the text field's states; the two that matter here are empty and filled.

EmptyFilledFocusDisabled
Search

Both themes

  • While the table loads for the first time the toolbar is shown disabled, so the layout does not jump when data arrives.

Responsive behaviour

  • The field has a 240 px basis and grows; at 360 px it takes the whole row and the selects wrap beneath it.
  • From 1024 px the three controls share one row.
  • The browser's own clear button appears in the field on engines that provide one; do not add a second.

Theming

It reads semantic tokens only, so both themes and prefers-contrast: more restyle it with no rule of its own.

Accessibility

Role and pattern

<input type="search"> inside a toolbar <div>. The result count under the table (“Showing 1–10 of 18,432 articles”) is in a polite live region so a filter change is announced.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
TypingFilters the list after a 300 ms pause.
EscClears the field in browsers that support it.

Focus

Focus stays in the field while results update. Clear search in the no-results state returns focus to the field.

Labelling

A visually hidden <label> (“Search articles”); the placeholder lists what can be searched and is not the label.

Motion

Nothing animates.

Touch

36 px tall with a fine pointer and 44 px (--target-comfortable) on touch devices, because --control-height-md grows under (pointer: coarse).

Content

  • The placeholder lists the searchable things: “Search titles, organisations, places”.
  • The no-results title repeats the query in quotation marks: “No articles match “pickleball””.
  • Search text is untrusted input: echo it as text, never as HTML.
