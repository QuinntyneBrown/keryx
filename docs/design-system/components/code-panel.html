Code panel

An ink panel with an example request and the response it returns.

Overview

The code panel shows consumers what to send and what comes back. It is ink in both themes, like the sidebar, so code always reads the same.

  • A head with a title and the response status in volt.
  • One or two blocks; the second (the response) is muted.

Anatomy

  1. HeadMono caption on a hairline; muted.
  2. StatusThe HTTP status in --color-brand (volt on ink).
  3. Block--text-code; scrolls sideways; focusable so it can be scrolled by keyboard.

Responsive behaviour

  • Long lines scroll inside the block; the panel never widens the page.
  • Under the endpoint list below 1024 px, beside it from 1024 px (L2-067).

Theming

Shell tokens only. In dark the panel is one step darker than the canvas. Volt is used for the status text because the background is ink.

Accessibility

Role and pattern

<pre> blocks with tabindex="0" and an aria-label, so a keyboard user can focus and scroll them (scrollable regions must be keyboard accessible).

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
ArrowLeft / ArrowRightScrolls a focused block sideways.

Focus

A volt ring inside the panel, as in the sidebar: the panel sets --color-focus-ring to --color-brand, because an ink ring would vanish on ink.

Labelling

Each block is labelled: “Example request”, “Example response”.

Content
