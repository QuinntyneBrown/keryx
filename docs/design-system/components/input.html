Component · Inputs

Text field

A single line of text: a URL, a name, a number of seconds, an e-mail address. On a <textarea> the same block takes several lines.

WCAG 2.2 AAStatus: stableNative <input>, <textarea>Block: .input, .input-affix

Overview

Use it for free text and for small numbers typed directly. Always inside a form field. For a choice from a fixed list use a select; for filtering a table use search.

  • Mono (.input--mono) for URLs and keys, where every character matters.
  • Short and medium widths hint at the expected length: three digits, an e-mail address.
  • Affix: a unit after the control (“seconds”, “months”, “runs in a row”).
  • Multi-line: the same class on a <textarea>, at least two lines tall, resizable vertically. No mock needs one yet.

Anatomy

  1. Control--control-height-md tall, --color-border-strong hairline edge (3:1), --radius-md, --space-3 inline padding.
  2. Suffix (optional)A muted unit after the control; part of the label's meaning, not of the value.
  3. Affix groupKeeps control and unit on one line with --space-2 between.

Sizes

One height, three widths.

.input--short 80 px · .input--medium up to --layout-field-max · default 100 %

States

Focus replaces the edge colour and draws the ring flush against it; invalid thickens the edge to 2 px in the danger colour.

  • Invalid is aria-invalid="true", never a class, and is always paired with an error message.
  • Disabled and read-only share a subtle fill; read-only stays focusable and selectable, disabled does not.

Responsive behaviour

  • Full width of its field by default, so it narrows with the dialog or the settings column.
  • Font size is 14 px; on iOS, where inputs under 16 px zoom the page on focus, the Angular component sets 16 px under (pointer: coarse).
  • The control is 44 px tall on touch devices. The suffix stays on the control's line.

Theming

The edge is --color-border-strong, the only border token that must reach 3:1 against the page and the card. It darkens on hover, becomes --color-focus-ring on focus and --color-danger-solid when invalid.

Accessibility

Role and pattern

A native <input> with the right type, inputmode and autocomplete (email on the alert address; off on source fields, which are not personal data).

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
TypingEdits the value. Validation runs on blur and again on each change once an error is showing.
EnterSubmits the form the field belongs to.

Focus

The ring is drawn with no offset so it reads as the field's own edge turning ink (or volt in dark). An autofocus field is used only as the first field of a dialog.

Labelling

A <label for> from the field. The suffix is not part of the accessible name, so the label carries the unit when it matters (“Timeout per source” + “seconds”).

Motion

Touch

36 px tall with a fine pointer and 44 px (--target-comfortable) on touch devices, because --control-height-md grows under (pointer: coarse).

Content

  • Pre-fill what Keryx already knows; never ask twice.
  • Placeholders are examples of the format, and only where the label cannot say it: “Search titles, organisations, places”.
  • Numbers that have a unit show it as a suffix, not inside the value.

BEM block: .input, .input-affix. The Angular component lives in frontend/projects/components/src/input/ and keeps these class names; the e2e page objects locate by them.
