Badge

A small pill that states a status or a count: Published, Needs review, 6.

Overview

Badges label the state of a record or count the items in a tab. They are not interactive; a pill you can press is a filter chip, and a removable value is a chip. For a status with an explanation in a table cell, use health.

  • Tones: neutral, success, warning, danger, info, brand.
  • Dot (.badge--dot): a 6 px dot in the solid status colour before the text, for record status.
  • Count (.badge--count): tabular digits, in tabs.

Anatomy

  1. Dot (optional)A --size-dot circle in the tone's solid colour, drawn with ::before.
  2. Label--text-overline (12 px medium).
  3. PillTone background, full radius, --space-0-5 by --space-2 padding; neutral has a hairline edge.

Responsive behaviour

  • Badges never wrap (white-space: nowrap) and never truncate.
  • Below 1024 px a table's status badge moves under the row title.

Theming

Each tone is a pair of status tokens: a pale tint with dark text in light, a deep tint with light text in dark. The dot uses the solid status colour, which is 3:1 or better on its tint in both themes.

Accessibility

Role and pattern

A <span> of text. The text carries the meaning; the colour and dot repeat it.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable.

Labelling

A count needs its noun from context: in a tab the name becomes “Needs review 6”. A lone count gets hidden text.

Motion

Content

  • One or two words, sentence case: “Needs review”, “Completed with issues”.
  • The same status always has the same word and tone everywhere: Published is green, Needs review amber, Hidden neutral.
  • Counts use thousands separators.
