Tag

Overview

A tag shows an identifier exactly as code uses it (articles:read). It is square-cornered and mono to tell it from a badge, which states a status in words.

  • Neutral only; a tag has no tone.
  • Several tags sit in a .cluster--xs.

Anatomy

  1. TagGeist Mono 12 px, muted, on --color-bg-subtle, --radius-sm.

Theming

Content
