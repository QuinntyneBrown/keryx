Component · Data display

Run chart

Fourteen bars, one per run, showing how many new articles each brought in and which runs had trouble.

Overview

The run chart is a sparkline with meaning per bar. Height is the count of new articles relative to the best of the fourteen; colour is the run's outcome. It is a glance, not an analysis tool: the Runs screen has the numbers.

  • Neutral bars for clean runs, amber for runs with issues, a red stub for a failed run, a pulsing volt bar for the run in progress.
  • No axes, no gridlines; a caption above says what is plotted.

Anatomy

  1. Plot--size-chart (56 px) tall, bars flexed evenly with --space-1-5 between.
  2. BarHeight from --value; --radius-xs; neutral is --color-border-inverse.
  3. Failed runA --space-1 stub in the danger colour: nothing was collected.

Responsive behaviour

  • Bars share the width equally; at 360 px each is about 14 px wide.
  • The chart never scrolls and never drops bars.

Theming

Neutral bars are ink-800 in light and ink-200 in dark, strong against the sunken strip in both. The running bar is volt: on the light strip it is low contrast by design and is never the only signal, because the headline says “Collecting news now…”.

Accessibility

Role and pattern

An <ol>; each bar is an <li> with visually hidden text (“Today 6:00 AM: 47 new”). The colour's meaning is in that text for failed and running bars.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable. It has no hover-only information in the product: the mocks' title tooltips duplicate the hidden text.

Labelling

The caption before it names the chart.

Contrast

Neutral bar on strip
Warning bar on strip
Failed bar on strip
Running bar (decorative in light)

Motion

The running bar pulses between full and half opacity every --duration-deliberate; the pulse stops under reduced motion.

Touch

Not interactive, so no target size applies.

Content

  • Hidden text per bar: “ : new”, or “: failed”.
  • The caption says the measure and the window: “New articles per run · last 14 runs”.

Code

BEM block: .run-chart. The Angular component lives in frontend/projects/components/src/run-chart/ and keeps these class names; the e2e page objects locate by them.

<li class="run-chart__bar" data-status="failed">
<span class="visually-hidden">Yesterday 12:00 PM: failed</span></li></ol>
Class / attributeEffect
.run-chartThe plot.
.run-chart__barA bar; --value is its height as a percentage of the tallest.
data-status="success|warning|failed|running"Outcome.
data-state="hover|focus|active"Documentation and mocks only: forces a pointer or focus state on a static page.
