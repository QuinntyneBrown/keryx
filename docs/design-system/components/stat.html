Stat

Overview

Stats are the headline numbers of a card. They are numbers the API serves as numbers; the label supplies the words. A row of them is a <dl class="stats">.

  • Label above, value below, in tabular figures.
  • A unit or denominator is set smaller and subtler after the value (“/64”, “ms”).
  • Three sizes of value; a danger tone for a number that is a problem.

Anatomy

  1. Label--text-caption, muted.
  2. Value--text-stat (24 px semibold, tight tracking, tabular).
  3. Unit16 px regular, subtle.

Responsive behaviour

  • .stats is three equal columns at every width; values are short enough to fit at 360 px.
  • .stats--4 is two columns below 640 px and four above.
  • In the status and summary cards the stats sit under the summary with a rule above, and move beside it with a rule at the left from 1280 px (768 px in the summary card).

Theming

It reads semantic tokens only, so both themes and prefers-contrast: more restyle it with no rule of its own. The danger value uses --color-danger-fg.

Accessibility

Role and pattern

A <dl>; each stat is a <div> wrapping a <dt> and its <dd>, so “New articles, 47” is read as a pair.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable.

Labelling

A unit that is a symbol gets spoken text if needed (“62 of 64”: the mock's “/64” is read “slash 64”; add hidden “of” in the product).

Contrast

Label
Unit
Danger value

Motion

Nothing animates. Numbers do not count up.

Touch

Not interactive, so no target size applies.

Content

  • Labels are two words at most.
  • Thousands separators; no more precision than is useful (“0.05%”, “84 ms”).
  • Zero is “0”, not blank. Unknown is an em dash.
