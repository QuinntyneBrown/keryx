Description list

Label and value pairs for one record: where an article came from, when it was collected, how it scored.

Overview

Use it for the facts of a single record, in the detail panel. This is where provenance is shown: organisation, source, and when Keryx first saw the item. Values can be text, a meter or badges.

  • Terms in a fixed 110 px column, values beside them.
  • A hairline and --space-5 above separate it from the summary.

Anatomy

  1. TermMuted, in a --layout-term-width column.
  2. ValueDefault text; may wrap or truncate.

Responsive behaviour

  • Two columns at every width; the panel is never narrower than 360 px, which leaves 200 px for values.
  • Long values wrap; a URL truncates with the full value in a tooltip and in the accessible name.

Theming

It reads semantic tokens only, so both themes and prefers-contrast: more restyle it with no rule of its own.

Accessibility

Role and pattern

A <dl> with <dt>/<dd> pairs, so each value is announced with its term.

Keyboard

KeyAction
—Not focusable. It is read in document order with the content around it.

Focus

Not focusable; a link inside a value is.

Labelling

Terms are the labels.

Contrast

Term
Value

Motion

Nothing animates.

Touch

Not interactive, so no target size applies.

Content

  • Terms are one word where possible, sentence case, no colon.
  • Order: who published it, where Keryx found it, what it is about, when.
  • A person named in a record appears only as the source published them; no contact details.
