Table

Rows of records with the same fields: articles, sources, API consumers. Real tables, so headers and cells are announced together.

WCAG 2.2 AAStatus: stableNative <table>Block: .table, .table-wrap

Overview

Use a table when people compare the same fields across many records. Keryx has three. Each has a primary column that holds the record's name and, on small screens, everything else stacked beneath it. A list of unlike things is a list.

  • The first column is the record: a title, a secondary line, and on phones the status and context that the hidden columns held.
  • Numeric columns are right-aligned with tabular figures.
  • Row actions sit in a fixed-width last column: an icon button with a menu, or one small ghost button.
  • Every table is paged on the server and ends with a table footer.

Anatomy

  1. WrapperSurface, hairline edge, --radius-lg; scrolls sideways if the table cannot shrink.
  2. Head--text-overline labels in muted text on --color-bg-surface-sunken.
  3. Rows--space-3 cell padding (--space-5 at the outer edges), a hairline between rows, a subtle fill on hover.

Sizes

One density: 12 px cell padding, about 56 px per two-line row. There is no compact variant; ten to twelve rows per page fit a laptop screen.

States

Row states are shown on the row; table states replace the body.

StateLooks like
Row hover--color-bg-subtle fill; the whole row is the title link's hit area.
Row selected--color-accent-subtle fill while its detail panel is open.
Row revokedSubtle text and a struck-through title; no actions.
LoadingSkeleton rows in the same columns, aria-busy="true" on the wrapper.
EmptyThe table is replaced by a first-run empty state.
No resultsThe body is replaced by a compact empty state; filters stay.
ErrorThe table is replaced by an error state with Try again.

Responsive behaviour

  • Below 1024 px only the primary column and the actions column remain (.from-lg hides the rest); status and context move into .table__stacked under the title (.until-lg). The table uses a fixed layout so long titles wrap instead of pushing it wide.
  • From 1024 px all columns show. With the detail panel open, between 1024 and 1535 px, .table__optional columns hide and .table__context shows them as a line under the title.
  • If a table still cannot fit, .table-wrap scrolls it horizontally; the page never scrolls sideways.
  • While a row menu is open the wrapper is .table-wrap--open so the menu is not clipped.

Theming

Head on the sunken surface, rows on the surface, hover on subtle, selection on accent-subtle (pale volt in light, deep olive in dark). All four are distinguishable in both themes and all text pairs pass on each.

Accessibility

Role and pattern

A native <table> with a <caption> (visually hidden, and saying the sort order), <th scope="col"> headers, and a hidden header for the actions column. Not a grid: cells are not individually focusable.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter on a title linkOpens the record's detail panel.
Enter / Space on a row actionOpens the row menu or runs the action.

Focus

Tab stops are the title link and the row action, row by row. The title link's ring is drawn around the title text. When a panel or dialog opened from a row closes, focus returns to that row.

Labelling

The caption names the table and its order: “Articles, newest first”. The selected row is marked with aria-current="true"; aria-selected is only valid in a grid. Row actions name their row.

Contrast

Head label
Cell text
Secondary text on hover
Text on selected row
Secondary text on selected row
Mono sub line on hover

Motion

Row fill changes over --duration-fast.

Touch

The whole row is the title link's target. Row actions are 32 px, 44 px on touch, in a 56 px column.

Content

  • Column headers are one or two words; units go in the header (“Articles · 30d”, “Requests · 24h”).
  • An empty cell is an em dash, never blank or “N/A”.
  • Titles and organisation names come from sources: render as text with dir="auto", never as HTML.
  • Times are relative when recent (“2h ago”) and absolute otherwise, Toronto time.

.tableThe table.
.table__primary / __title / __subThe record cell: title and secondary lines; __sub--mono for URLs.
