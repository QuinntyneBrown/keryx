Meter

A tiny bar and a two-decimal number for an article's relevance score.

WCAG 2.2 AAStatus: stableBar + numberBlock: .meter

Overview

The meter makes a column of scores scannable: the bar gives the shape, the number the fact. It always shows both. It is not a progress bar; for progress use progress.

  • Tone follows the thresholds in Settings: success at or above the publish threshold, warning in the review band, neutral below.

Anatomy

  1. Track40 × 6 px, --color-border-default, full radius.
  2. FillWidth from --value; the tone colour.
  3. ValueCaption-size tabular number, muted.

Responsive behaviour

  • Fixed size. The Relevance column is hidden below 1024 px; the score is then in the detail panel.

Theming

The fill is a solid status colour on the divider-coloured track, 3:1 or better in both themes. The number is the accessible value either way.

Accessibility

Role and pattern

The track is aria-hidden; the number is plain text in a table cell headed “Relevance”. No role="meter" is needed because the value is already text.

Keyboard

—Not focusable. It is read in document order with the content around it.

Content

  • Two decimals, always: “0.94”, “0.60”.
  • The same thresholds as Settings; when a threshold changes, tones change with it.
