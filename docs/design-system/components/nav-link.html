Navigation link

One destination in the sidebar: an icon, a word, and sometimes a count of what needs attention there.

Overview

Navigation links live only in the sidebar, on ink. The current page is marked three ways: a raised fill, medium weight, and a volt icon with a volt bar at the left edge.

  • The count badge appears only on Runs, when sources are failing.
  • Links are real anchors; the router sets aria-current="page".

Anatomy

  1. Icon16 px; volt when current.
  2. Label14 px; muted, or light and medium weight when current.
  3. Count badge (optional)An 18 px danger pill pushed to the right edge.
  4. Row--control-height-md, --radius-md; a 2 px volt bar at the left edge when current, from 1024 px.

  • There is no disabled link. A destination the person may not open is not rendered.

Responsive behaviour

  • From 1024 px links stack and fill the sidebar's width; the current one shows the volt bar.
  • Below 1024 px they sit in a row, keep their natural width and scroll sideways; the bar is dropped and the fill and icon mark the current page.
  • 44 px tall on touch devices.

Theming

The link reads shell tokens, which stay ink in both themes. Volt appears only as the current icon and bar: a fill on ink, never text.

Accessibility

Role and pattern

An <a href> inside the primary <nav>; aria-current="page" on the current one.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterGoes to the destination.

Focus

A volt ring (the sidebar overrides the ring colour).

Labelling

The visible word is the name. The count is announced through visually hidden text (“Runs, 2 failing sources”), not through aria-label on a <span>, which screen readers may ignore.

Contrast

Motion

Colour changes run over --duration-fast (150 ms) with --ease-standard; the token is zero under prefers-reduced-motion, so the change is instant there.

Touch

36 px tall with a fine pointer and 44 px (--target-comfortable) on touch devices, because --control-height-md grows under (pointer: coarse).

Content

  • One word, a noun, title case as a proper screen name: Overview, Articles, Runs, Sources, API, Settings.
  • The count is a number only; its meaning is in the hidden text.
  • Icons are fixed per destination; see iconography.
