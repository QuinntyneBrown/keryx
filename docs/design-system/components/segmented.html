Segmented control

A row of two to five mutually exclusive options where all of them are visible and one is always chosen.

WCAG 2.2 AAStatus: stableButton groupBlock: .segmented

Overview

Use it for a small, fixed set that changes what the screen shows or one setting's value: the run filter (All runs / With problems) and the schedule (1 hour … Day). For a filter with more options or that wraps, use filter chips; for sections of a screen, tabs.

  • One option is always selected; choosing another deselects it.
  • The selected segment is filled with the accent: ink in light, volt in dark.

Anatomy

  1. TrackSurface with a hairline edge, --radius-md, --space-0-5 padding.
  2. Selected segment--color-accent fill with --color-fg-on-accent text; aria-pressed="true".
  3. Segment--control-height-sm tall, muted label, darker on hover.

Variants

As a filter it sits above the list it filters; as a setting it sits in a <fieldset> whose legend is its label.

Sizes

One size: segments are <code>--control-height-sm</code> (32 px, 44 px on touch).

States

A segment is either pressed or not; the whole control can be disabled while its form is saving.

DefaultHoverFocusSelectedDisabled group
Segment

Both themes

  • Disabled: aria-disabled="true" on the group dims it to --opacity-disabled; each button is also disabled.

Responsive behaviour

  • The track is inline-flex and wraps: five schedule options fit on one row at 360 px, and would wrap inside the track rather than overflow if labels grew.
  • Never more than five segments; use a select beyond that.
  • Segments grow to 44 px tall on touch devices.

Theming

The selected fill is --color-accent, so it follows the primary button: ink in the light theme, volt with ink text in the dark theme.

Accessibility

Role and pattern

A role="group" with aria-label (or a <fieldset> with a legend) containing <button aria-pressed> elements. Each button is in the tab order; there is no roving focus.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter / SpaceSelects the focused segment and deselects the previous one.

Focus

The shared ring (--focus-ring-width of --color-focus-ring, offset by --focus-ring-offset) appears on :focus-visible only, so a pointer click does not show it. It is ink in the light theme and volt in the dark theme, on the sidebar and on toasts. The ring is drawn outside the segment, over the track's padding.

Labelling

The group needs a name (“Filter runs”, legend “Run every”). Each segment is its text. The pressed state is announced by aria-pressed, not by colour alone.

Motion

Colour changes run over --duration-fast (150 ms) with --ease-standard; the token is zero under prefers-reduced-motion, so the change is instant there.

Touch

32 px with a fine pointer and 44 px on touch devices: --control-height-sm grows to --target-comfortable under (pointer: coarse).

Content

  • One or two words per segment, parallel in form: “1 hour”, “3 hours”, “6 hours”, “12 hours”, “Day”.
  • Order by magnitude or by how often it is used, never alphabetically.
  • State the consequence under a setting: “cron: 0 */6 * * * · next 12:00 PM”.
