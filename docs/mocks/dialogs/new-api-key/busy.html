Endpoints

  • GET/v1/articles Published articles, newest first. Filter by region, category, org, since.
  • GET/v1/articles/{id} One article with summary, tags and canonical link.
  • GET/v1/organizations Christian fitness organisations Keryx tracks.
  • GET/v1/categories Categories and article counts.
  • GET/v1/status Last run time and pipeline health, for consumers to show freshness.
